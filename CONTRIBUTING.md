# Contributing to Food Delivery App

Thank you for your interest in this project!

## How to Contribute

1. **Fork the repository**: [https://github.com/Abhishek-bhagat9/Food-Delivery-App](https://github.com/Abhishek-bhagat9/Food-Delivery-App)
2. **Clone your fork**:
    ```bash
    git clone https://github.com/<your-username>/Food-Delivery-App.git
    cd Food-Delivery-App
    ```
3. **Create a new branch**:
    ```bash
    git checkout -b feature-or-bugfix-description
    ```
4. **Make your changes** and test them.
5. **Commit your changes**:
    ```bash
    git add .
    git commit -m "Description of the feature or bugfix"
    ```
6. **Push and open a Pull Request** to the `main` branch.

## Guidelines

- Follow the existing code style.
- Write clear commit messages.
- Add comments for complex sections.
