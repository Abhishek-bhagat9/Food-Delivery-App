# 🍔 Food Delivery App

A full-featured multivendor food delivery application built with React Native.

## About

This is a personal project by **[Abhishek-bhagat9](https://github.com/Abhishek-bhagat9)**, showcasing a complete food delivery platform with support for multiple vendors, riders, restaurants, and customers.

## Project Structure

| Module | Description |
|--------|-------------|
| `enatega-multivendor-admin` | Admin dashboard |
| `enatega-multivendor-app` | Customer mobile app |
| `enatega-multivendor-restaurant` | Restaurant management app |
| `enatega-multivendor-rider` | Rider/delivery app |
| `enatega-multivendor-web` | Customer web frontend |

## Getting Started

### Prerequisites
- Node.js (v14–v16)
- npm or yarn
- React Native CLI

### Installation

```bash
git clone https://github.com/Abhishek-bhagat9/Food-Delivery-App.git
cd Food-Delivery-App
npm install
```
