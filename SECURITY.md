# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please follow the steps below:

1. **Contact**: Open a private [GitHub Security Advisory](https://github.com/Abhishek-bhagat9/Food-Delivery-App/security/advisories/new) or email the maintainer directly via GitHub.

2. **Provide details**:
    - A clear description of the vulnerability.
    - Steps to reproduce it.
    - Potential impact.
    - Suggested fix (if any).

3. **Acknowledgment**: You will receive a response within 48 hours.

4. **Disclosure**: Please do not disclose the vulnerability publicly until a fix has been released.
